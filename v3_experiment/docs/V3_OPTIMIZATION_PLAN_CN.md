## 0. 结论先行

**推荐主行动 = A1(sootspike 补齐全局 256 配方重训),定位:补齐关键对照 + 尝试改善性能。**

- **它是合理对照,不是已证实的最佳优化方向。** 样本量算术(256/56 ≈ 4.6 倍)正确,
  但不能据此认定配方是最大瓶颈,更不能认定增大 batch 必然提升。
- **2026-09-10 补充**:v2 80k 对照产物当前无法取得(§1 D-d 定位证据),A1 是当前可执行的
  **同文本、不同 batch 配方对照**——注意它**仍不是纯单变量**:固定 80k 更新次数下,
  batch 与累计样本量(80k×256 vs 80k×56)同时改变,收益无法分解到其中一项。D1 的 EMA
  敏感性(§2.1)是"当前配方末期优化或终点选权重存在敏感性"的**候选证据之一**,不构成
  对大 batch 方向的验证;A1 仍是验证实验。
- **A1 回答的问题是**:固定 80k 更新次数下,换成大 batch 配方的整体效果。它同时改变
  micro-batch 分布与累计样本量(80k×256 vs 80k×56),**无法区分收益来自哪一项**;
  文本归因靠它与 v2 的对照(前提:先核验 v2 实际配方,§3-A1)。
- KD 侧事实只作记录,不作推断:v3(KD student)低于官方 ckpt(KD teacher),四套件
  −11.3pp。**学生低于 teacher 不能排除蒸馏侧问题**——KD 权重、特征匹配方式、teacher
  输入设置都可能影响学生;蒸馏假设与容量/配方假设并存,由后续消融区分。

### 2.1 D1 结果与解释边界(2026-09-10)

**数据**(输出目录 `.../output/eval/v3_sootspike_step_80000_ema_clean_8f1084e/`):

| 套件 | raw(主表) | EMA(D1,补充口径) | 差值 |
|---|---|---|---|
| libero_goal | 80.8%(404/500) | **95.2%**(476/500) | +14.4pp |
| libero_goal task5 | 2%(1/50) | **98%**(49/50) | +96pp |
| libero_spatial | 78.2%(391/500) | **95.6%**(478/500) | +17.4pp |
| libero_object | **99.2%**(496/500) | 98.0%(490/500) | −1.2pp |
| libero_10 | 67.6%(338/500) | **80.0%**(400/500) | +12.4pp |
| 四套件合计 | 81.5%(1629/2000) | **92.2%**(1844/2000) | +10.8pp |

**当前可以确认的**(四套件口径):

- 该 checkpoint 的 EMA 与 raw 行为差异极大;EMA 值得作为独立权重口径继续评测;
- raw 上的 task5 崩塌不是唯一、稳定的模型行为——**该行为对权重选择高度敏感**;
- EMA vs 官方 raw 锚点:goal/spatial 略超(+0.8/+2.0pp),object 持平(−0.8,噪声内),
  libero_10 仍差 −4.0pp;四套件合计 92.2% vs 92.7%,噪声内打平;
- **EMA 增益不是无条件的**:raw 已接近官方的 object 上 EMA 持平微降(−1.2pp),增益
  集中在 raw 落后的 spatial/goal/10(+17.4/+14.4/+12.4pp);10-t9 EMA 仍仅 24%(raw 28%);
- 视频(D3)描述的是 **raw 权重在该任务上的真实失败现象**,仍然成立;EMA 结果表明它
  不能被归为模型固有缺陷,但也不因 EMA 结果而否定 raw 失败的存在。

**不能直接推出的**(防止解释过远):

1. **"训练末期权重不稳定实锤"**——单终点的两份权重只能说明**权重选择敏感**,即"提示
   末期优化或终点选权重存在敏感性";要证明末期震荡,需多个 checkpoint 或多个 seed 的
   raw/EMA 曲线。EMA/raw 同 launcher、同 seed 7、同 50 trials、同 chunk 12、同 fp32、
   同 LIBERO commit(协议字段逐项核对一致;渲染节点可能不同,同为 H100,跨节点数值
   一致性未单独验证)。加固手段:补 70k/75k/80k 多 checkpoint 的 raw/EMA 曲线(单套件
   goal 即可;ckpt 均在 /data)——候选诊断,不排期、不阻塞。
2. **"直接支持大 batch 方向"**——EMA 增益支持"当前小 batch 或末期优化可能存在问题"这一
   **候选**,但也可能来自 EMA 本身、学习率末期状态、checkpoint 选点或评测随机性。
   A1 仍是验证实验,D1 不写成大 batch 已被验证。
3. **"真实能力更接近官方"**——正确表述:**在 EMA 口径下,goal 观测成绩(95.2%)接近
   官方 raw 锚点(94.4%)**。官方锚点是 raw,EMA-vs-raw 是权重口径差异,不称"真实能力"。

**候选机制假设(待验证,非已测因果)**:训练日志 dump 显示 `min_lr_ratio=1.0`(lr 至 80k
步不衰减,恒定 5e-5)+ batch 56 → 末期权重可能持续震荡,EMA 平均后落入轨迹中心;官方
同 lr 策略但 batch 256,梯度噪声直觉估算缩小 √(256/56)≈2.1 倍(**直觉估算,非实测**)。
该假设由 A1(大 batch)与多 checkpoint 曲线共同检验,当前不作为结论使用。

**后续结论顺序(四步已全部完成)**:spatial EMA ✅ → 增益确认为全局(spatial/goal)→
补 object/libero_10 EMA ✅(2026-09-10 完成,四套件 EMA 合计 92.2% vs 官方 raw 92.7%,
噪声内打平)→ raw 与 EMA 分别报告 ✅(对比 MD §5)→ **下一步:决定 A1 配置与是否
采用 EMA 部署**(EMA 若采用,须预注册 raw/EMA 选择规则并对所有模型统一执行;A1 的
价值重心已从"救成绩"转向"检验 batch/累计样本量假设 + v4 前置验证")。

**D2 附带核验清单(以 v2 ckpt 存储的 args/model_config + 启动日志为准,不凭计划文档)**:
lr 与分组、KD 配置、精度组合、初始化来源、micro-batch × accum 的实际组合、评测用的
raw/EMA。核验通过后,"A1 vs v2 = 文本单变量"才成立。
