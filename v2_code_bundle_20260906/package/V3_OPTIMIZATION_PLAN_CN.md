## 0. 结论先行

**推荐主行动 = A1(sootspike 补齐全局 256 配方重训),定位:补齐关键对照 + 尝试改善性能。**

- **它是合理对照,不是已证实的最佳优化方向。** 样本量算术(256/56 ≈ 4.6 倍)正确,
  但不能据此认定配方是最大瓶颈,更不能认定增大 batch 必然提升。
- **2026-09-10 补充**:v2 80k 对照臂确认不存在(§1 D-d),A1 同时是造出这一对照臂的
  唯一动作——定位不变(候选解释的对照),但缺口比原先认定更大。
- **A1 回答的问题是**:固定 80k 更新次数下,换成大 batch 配方的整体效果。它同时改变
  micro-batch 分布与累计样本量(80k×256 vs 80k×56),**无法区分收益来自哪一项**;
  文本归因靠它与 v2 的对照(前提:先核验 v2 实际配方,§3-A1)。
- KD 侧事实只作记录,不作推断:v3(KD student)低于官方 ckpt(KD teacher),四套件
  −11.3pp。**学生低于 teacher 不能排除蒸馏侧问题**——KD 权重、特征匹配方式、teacher
  输入设置都可能影响学生;蒸馏假设与容量/配方假设并存,由后续消融区分。

## 3. Phase 1:优化与消融(定位均为"检验假设",不预设瓶颈归属)

### A1|sootspike @ 全局 256 重训(主行动:补齐关键对照 + 尝试改善)

- 配方:**对齐 v2 的训练配方 + 官方的指定超参数**(全局 256、80k 步、warmup 10k、seed 42;
  v2 相对官方保留的差异——SNN 结构、融合初始化、KD 等——照旧继承;**不写"完全对齐官方"**)。

- 能回答:大 batch 配方在固定更新次数下的整体效果;v2-vs-A1 文本对照(核验后);
  v3-vs-A1 batch 对照。
- 不能回答:收益来自 batch 还是累计样本(两者同时改变);文本与 batch 的交互项。
- 成本:4 卡约 2–4 天。

### A2|视觉消融(SDT-V3 → DINOv3 ViT-B,其余同 A1)——**假设检验,非归属判定**

- 触发条件:**D2 显示 v2 也显著低于官方**。此时"(batch 56 + 换 sootspike)"不足以解释
  差距,**剩余候选 = 视觉/融合、两类脉冲文本的共性问题、两组共享的 KD/初始化/配方**——
  不能把差距直接归给视觉/融合。
- A2 的作用:若换 DINOv3 后显著收敛 → 支持视觉(单模块)瓶颈假设;若未改善 → 只说明
  **本次视觉替换未带来改善,不能排除视觉与其他模块的交互瓶颈**;候选保持开放:
  视觉/融合及其交互、两类脉冲文本共性、共享 KD/初始化/配方。
- 代价:三组件 spike → 两组件(视觉不再 spike),实验故事变化,启动前单独拍板。
